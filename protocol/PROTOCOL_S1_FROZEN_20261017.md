# S1 正式实验冻结协议（2026-10-17，开跑前写定）

**题目（暂定）**：What Actually Drives Mamba-Based Sequential Recommenders? Selectivity, Recency, and the Last Item
**代码**：`s1_lib.py`（模型、训练、评测），`s1_run.py`（调参 / 最终运行），`s1_queue.sh`（队列）。试验阶段代码 `../seq_common.py` 不再改动。
**来源说明**：本协议的假设 H2 来自试验阶段（Baby、Sports 各 2 个种子）的观察，论文中必须如实披露"假设由试验数据启发，正式实验用全新的调参、种子与数据集检验"。

## 1. 研究问题

- RQ1　选择性（Δ、B、C 随输入变化）相对时不变版本到底带来多少增益？
- RQ2　固定近因滤波（EMA）、"最后一个物品"、"最后一个物品 + 历史均值"能解释多少性能？
- RQ3　模型对顺序和对最近一个物品的依赖有多大（两种测试时安慰剂）？在哪些用户上（按历史长度、目标流行度分层）？
- RQ4　结论在什么条件下失效？用长序列、强序列性的 MovieLens-1M 检验边界。
- RQ5　效率：参数量、每轮训练时间、推理延迟。

## 2. 数据

| 数据集 | 来源 | 划分 | 最大长度 |
|---|---|---|---|
| Amazon Baby / Sports / Clothing | 本地 5-core（paper4 数据） | 现有留一法（按时间：最后一个测试、倒数第二个验证） | 50 |
| MovieLens-1M | GroupLens 官方 | 同样的留一法，全部评分视为隐式交互 | 200 |
| Amazon Electronics（规模检验） | 本地 | 同上 | 50 |

## 3. 模型

外壳完全相同，只换序列混合器（见 `s1_lib.py` 文件头）：物品嵌入 → dropout → LayerNorm → 2 个块 ×［混合器 → 残差 → LN → FFN → 残差 → LN］→ 取最后位置；输出层与输入嵌入共享；全量 softmax 交叉熵，所有位置都作为训练目标。

混合器：`last`（不混合）、`mean`（因果均值）、`ema`（固定形式近因滤波）、`lti`（时不变 Mamba 块）、`mamba`（选择性 Mamba 块，即 Mamba4Rec 的混合器）、`sasrec`（因果自注意力）、`gru`（GRU4Rec，打包序列，单层）。所有模型 d=64，状态维 16，块数 2（GRU 为 1 层循环）。SSM 在 GPU 上用 mamba_ssm 官方 CUDA 扫描核（已与纯 PyTorch 递推逐元素核对，最大差 1e-5）。

## 4. 调参与种子

- 网格：学习率 {1e-3, 3e-3} × dropout {0.2, 0.5}，种子 0，每个（数据集，模型）按验证集 NDCG@10 选最优配置。所有模型同样预算。
- 最终：选定配置下种子 0–4（共 5 个），只在最终运行读测试集指标。
- Electronics：不单独调参，沿用 Sports 上选出的配置，种子 0–2。
- 训练：Adam，batch 256，最多 200 轮，每 2 轮验证，连续 5 次不提升早停，取验证最优的权重。

## 5. 指标与分析

- 主指标：测试集 NDCG@10（同时报告 HR@10/20、NDCG@20），全量排序，历史物品屏蔽，并列按悲观方式计名次。
- 逐用户名次全部落盘，任何后续分层都可离线重算。
- 分层：目标物品训练流行度（≤5 / 6–20 / >20）；历史长度三分位。
- 安慰剂（测试时，不重训）：(a) 打乱历史顺序；(b) 去掉最近一个物品。
- 效率：参数量、每轮训练秒数、全目录打分的推理延迟（GPU，毫秒/用户）。

## 6. 预注册假设与判据

统计：按（数据集，种子）配对；配对相对增益的 95% bootstrap 置信区间（20,000 次）+ 精确 Wilcoxon；同一族比较做 Holm 校正。

| 编号 | 假设 | 判据 |
|---|---|---|
| H1 | 选择性在短序列电商数据上增益很小 | 三个 Amazon 数据集合并，mamba 对 lti 的配对相对增益 95% CI 上界 < 3% |
| H2 | 简单混合器不劣于 Mamba（短序列电商） | 三个 Amazon 数据集合并，mean 对 mamba 的配对相对差 95% CI 下界 > −3%（非劣界 3%） |
| H3 | 依赖最近一个物品 | 去掉最近物品后，mamba 的 NDCG@10 在每个 Amazon 数据集上下降 ≥ 20% |
| H4 | 边界：长序列强序列性数据上，序列建模有用 | ML-1M 上 mamba 与 sasrec 都比 mean 高 ≥ 5%，且 CI 下界 > 0 |
| H5 | 边界：长序列上选择性有用 | ML-1M 上 mamba 对 lti 的配对增益 CI 下界 > 0 |

每个数据集单独的结果也全部报告。任何一条不成立都如实写进论文；不因结果调整网格、种子或判据。
